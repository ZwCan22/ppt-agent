# 自动检查怎样运行

项目根目录 CMD 执行 `deploy\test-all.cmd`。它启动 ppt-agent-tests 测试 Compose 项目，再执行后端单元测试、数据库集成测试和前端构建。任一步失败即返回非零退出码。前提：已安装 .venv 锁定依赖和 frontend 的 npm 依赖。

测试数据库已运行时可执行：

```bat
.venv\Scripts\python.exe -B deploy\check_all.py --frontend
```

只运行集成测试：

```bat
.venv\Scripts\python.exe -B -m unittest discover -s backend\integration_tests -t backend -v
```

## 覆盖范围

| 分类 | 数量 | 检查 |
|---|---:|---|
| Dify 单元测试 | 5 | 合法大纲、页数、类型位置、工作流失败、无效 JSON |
| 查询与下载 | 4 | 自己可查、他人不可查、匿名拒绝、所有者才可下载 |
| 幂等性 | 4 | 重试复用、内容冲突、用户隔离、新编号创建 |
| 并发提交 | 1 | 两个独立连接同时提交同一编号，只保存一个任务 |
| 登录与会话 | 5 | 注册登录/Cookie、过期、退出撤销、错误密码、停用用户 |
| 任务历史 | 3 | 所有者/旧任务隔离、分页、匿名和非法分页 |
| Worker | 9 | 竞争领取、续租、恢复、重试上限、失效凭证、状态保护、心跳失效 |
| 数据库迁移 | 4 | 空库升级与模型一致性、回退再升级、业务权限、外键漂移检测 |

## 隔离方式

普通接口测试由 support.py 建立外层事务，业务代码的 commit/rollback 在 SAVEPOINT 中执行，测试后回滚外层事务。每项测试使用自己的 FastAPI 小应用。

并发与 Worker 使用真实提交，committed_support.py 为每项测试创建随机 test_<UUID> Schema，并把测试期间的服务连接指向该 Schema。结束后只删除该随机 Schema。

迁移测试创建 test_migrate_<UUID> 临时数据库，执行真实 bootstrap 与 Alembic 迁移，只删除通过名称校验的临时数据库。测试实例保留两个 NOLOGIN 角色 ppt_admin/ppt_app，用于验证真实权限。生产库不执行降级。

连接固定为 127.0.0.1:15433/ppt_agent_test、ppt_test，先验证身份再写入；业务实例使用 15432。测试不读取真实模型响应，不需要 Dify Key。

## 替代与边界

权限/幂等测试指定测试用户；AuthSessionTests 撤销该替代，执行真实注册、密码校验、Cookie 与会话查询。

下载测试使用固定字节临时文件，只验证下载权限，不证明 PPT 格式或排版正确。心跳失效测试以可控续租结果触发；其他租约测试执行真实 SQL，并移动租约时间，避免等待 120 秒。

## CI

task-access-ci.yml 扩展为 Backend integration CI，检查名称 PostgreSQL integration tests；GitHub 准备临时 PostgreSQL 17，执行同一套测试。后端单元测试、前端构建仍独立报告。

Alembic 入口接受 Config.attributes 中的已有连接；手动执行仍交互输入 ppt_admin 密码。比较时将默认 public Schema 规范化到元数据副本，避免反射误报；缺失外键测试确认仍检测真实差异。

## 排错

- 15433 连接被拒绝：检查 Docker Desktop 与测试容器。
- Refusing to run：使用独立 Python 进程，不在已加载业务配置的 Python Console 中运行。
- CREATE DATABASE/ROLE 被拒绝：测试需测试实例初始化的 ppt_test 管理权限，业务账号无需这些权限。
- 断言失败：看测试名与预期/实际值，不删除断言绕过问题。
- 强制结束可能留下临时对象；正常运行会清理。处理遗留对象前确认实例与对象名称。
